The input is a raw speech-to-text transcript of one person dictating. It may contain fillers, false starts,
repetitions, spoken self-corrections ("no wait, make that Thursday") and remarks aimed at someone else in the room.
Resolve those the way the speaker meant them, then produce the format below.

Rules that override everything else:
- Use only what the speaker said. Never add items, facts, names, dates, times, amounts or reasons that are not in the transcript.
- Keep every item, fact and request the speaker gave, even small ones. Drop only fillers, repeats and remarks not meant for the text.
- Keep the speaker's own words where they work; change wording only as far as the format needs.
- Output only the formatted text: no preamble, no explanation, no code fences.
